# Task 03: Features and Tuning

## Project Overview

This project demonstrates feature engineering and hyperparameter tuning using a machine learning classification model.

## Dataset

Breast Cancer Wisconsin dataset provided by Scikit-learn.

## Tools and Technologies

* Python
* Pandas
* NumPy
* Scikit-learn
* Google Colab
* Random Forest Classifier
* GridSearchCV

## Project Tasks

1. Loaded and inspected the dataset.
2. Created two new engineered features.
3. Split the dataset into training and testing sets.
4. Evaluated the baseline model using five-fold cross-validation.
5. Applied GridSearchCV for hyperparameter tuning.
6. Compared model performance before and after tuning.
7. Evaluated the final model on the test dataset.

## Results

The notebook contains the cross-validation scores, best hyperparameters, performance comparison, and final test evaluation.

## How to Run

Open the notebook in Google Colab and run the cells sequentially.
